# Cisco-Network-Notes
Cisco Network Learning Note

## 📖 CCNA 

* **Network Fundamentals**: OSI 模型、TCP/IP、IPv4/IPv6 子網劃分（Subnetting）。
* **Network Access**: VLANs、Trunking（802.1Q）、STP/RSTP、EtherChannel。
* **IP Connectivity**: 靜態路由（Static Route）、OSPFv2 基礎。
* **IP Services**: DHCP、NAT/PAT、NTP、ACL 訪問控制列表。
* **Security & Automation**: 設備安全基礎、自動化與架構概念（DNA Center, RestAPI）。

---

## 🧠 CCNP 

ENCOR & ENARSI
* **Layer 3 Routing**: OSPFv3、EIGRP 進階、BGP 鄰居建立與策略調優、路由重分發（Redistribution）。
* **VPN & Overlay**: GRE Trunk、DMVPN、VXLAN 基礎。
* **Infrastructure Security**: AAA 架構、CoPP（Control Plane Policing）、802.1X 認證。
* **Network Automation**: Python 網絡自動化腳本（Netmiko、Paramiko）、Ansible 自動化部署。
